📌 Description

Python Knowledge Quiz is a simple command-line quiz game written in Python. It tests the user's knowledge of basic Python concepts through multiple-choice questions. The program checks each answer, calculates the final score, and displays the user's results.

🎯 Features
Multiple-choice Python questions
Accepts answers using A, B, C, or D
Automatically checks answers
Displays the correct answer when the user is wrong
Keeps track of the user's score
Calculates the final percentage
Displays both correct answers and user guesses

▶️ How to Run
Make sure Python is installed on your computer.
Save the program as:
Python Knowledge Quiz.py
Open a terminal in the project folder.
Run:
python "Python Knowledge Quiz.py"
Answer each question by entering A, B, C, or D.
🧪 Example
--------------------------
Who created Python?
A. Dennis Ritchie
B. James Gosling
C. Guido van Rossum
D. Bjarne Stroustrup

Enter your option (A, B, C, D): C
It's correct!

At the end, the program displays:

--------------------------------------
              Results
--------------------------------------

Answers: C B B A C
Guesses: C B B A C

Your total score is 100%
📊 Scoring

The score is calculated using:

score / total_questions * 100

For example:

5/5 → 100%
4/5 → 80%
3/5 → 60%
2/5 → 40%
1/5 → 20%
